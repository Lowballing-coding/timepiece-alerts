    Make alerts loud on iPhone

    A web app can't override silent mode by itself. Do this once:
    1. Add to Home Screen first (Share, then Add to Home Screen) and open the app from there.
    2. Settings, then Notifications, then Timepiece: Allow Notifications on, Sounds on, Banner style Persistent.
    3. If you see Time Sensitive Notifications, turn it on.
    4. Settings, then Focus: in each Focus you use (Sleep, Do Not Disturb), open Apps and allow Timepiece.
    5. Keep the ringer switch on (not silent) if you want sound.
