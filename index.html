        Make Alerts Loud on iPhone

        A web app can't override silent mode by itself. Set this up once:

        1. Add the app to your Home Screen (Share, then Add to Home Screen) and open it from there.
        2. In Settings, go to Notifications, then the app. Turn on Allow Notifications and Sounds, and set Banner Style to Persistent.
        3. If you see Time Sensitive Notifications, turn it on.
        4. In Settings, go to Focus. In each Focus you use (Sleep, Do Not Disturb), open Apps and allow this app.
        5. Leave the ringer switch on if you want sound.
